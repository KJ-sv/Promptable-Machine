How to Use This Classifier

  1. Open the site in your browser.
  2. Add training examples:
    • In Example text, type a short sentence (e.g., This is great!).
    • In Label, type the category (e.g., positive or negative).
    • Click Add example. Repeat—aim for 5–10 examples per label.
  3. Train the model:
    • Go to “2) Train the classifier” and click Train model.
    • Wait until it says Done.
  4. Predict:
    • Type a new sentence in Text to classify.
    • Click Predict label to see the result and confidence.
  5. Save / Load:
    • Download CSV saves your examples (headers: text,label).
    • Upload CSV loads examples back in.

Quick Tips

  • If Add example is gray, make sure both text and label have content.
  • Use consistent labels (e.g., always positive and negative).
  • More balanced examples → better model.

Troubleshooting

  • Can’t train? You need at least 2 labels and 2+ examples total.
  • Dropdown not showing? You can type labels manually.
  • Weird predictions? Add more training examples and retrain.
